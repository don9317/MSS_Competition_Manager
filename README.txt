MSS COMPETITION SCHEDULER v0.2

Open START_HERE.html.

Supported event formats:
- Tournament
- League
- League with season-ending tournament
- Camp / Clinic
- Tryout / Showcase

Major features:
- Single or multiple facilities
- Court and space availability
- Divisions, teams, groups and staff
- MSS registration CSV import prototype
- League and pool schedule generation
- Scores, standings and seeded opening-round brackets
- Camp, clinic, tryout and showcase session scheduling
- Public schedule filters
- CSV schedule export
- JSON setup import/export
- Browser auto-save

This is a standalone prototype. No installation is required.
